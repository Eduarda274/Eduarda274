## 🚀 Projetos em destaque

### 🚢 Análise de Dados do Titanic

Meu primeiro projeto de análise exploratória de dados, praticamente o "Hello World" do Data Science. :)

Utilizei **Python, Pandas e Matplotlib** para explorar o dataset do Titanic e investigar como fatores como sexo, classe e idade estavam relacionados à sobrevivência dos passageiros.

O projeto inclui análise exploratória, visualizações e um relatório com os principais resultados.

🔗 [Ver projeto](https://github.com/Eduarda274/analise-titanic)

### 🩺 Plataforma de Apoio ao Diagnóstico com IA

Projeto colaborativo desenvolvido durante uma **Residência Tecnológica do Bolsa Futuro Digital na UFPE**.

A plataforma foi criada para reunir ferramentas de apoio à análise de diferentes condições de saúde utilizando recursos de Inteligência Artificial.

Minha atuação foi principalmente no **Back-end com Python e Django**, incluindo desenvolvimento da API de login, APIs de usuários, CRUD, validações e integração com o restante da aplicação.

O projeto foi desenvolvido em equipe utilizando Git, branches e Pull Requests.

Como o código-fonte original está em um repositório privado da equipe, criei uma documentação pública mostrando o projeto, algumas telas e minha participação no desenvolvimento.

🔗 [Ver projeto](https://github.com/Eduarda274/residencia-bfd)
